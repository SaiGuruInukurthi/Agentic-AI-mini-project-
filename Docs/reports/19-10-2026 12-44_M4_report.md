## What was built
- `app/verdict.py` — pure functions, unit tested:
  - `compute_score`: `sum(sign*weight)/sum(weight)` with sign +1/-1/0 (supports/contradicts/unclear), weight = credibility × confidence; zero-weight-safe (returns 0.0 when no weighted findings).
  - `compute_verdict`: <2 clear-stance findings → Unverifiable; score ≥ 0.4 → True; ≤ -0.4 → False; else Mixed.
  - `format_findings_for_llm` — numbered findings for the summarizer prompt.
- `app/graph.py` — `summarize` node is now real: verdict ALWAYS from the formula (never the LLM); explanation from the LLM with graceful fallback if the LLM fails.
- `cli.py` — runs the full graph and prints verdict, score, explanation, and a source table. UTF-8 stdout reconfigure added (Windows cp1252 consoles crash on characters like U+202F in LLM output — found in the live run).
