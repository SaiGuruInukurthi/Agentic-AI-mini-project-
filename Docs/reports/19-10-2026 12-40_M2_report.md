# M2 Report — 19-10-2026 12-40

## Scope
M2: custom evidence MCP server (`extract_passages`, `source_credibility`, `extract_date`), wired into the read agent.

## What was built
- `mcp_servers/evidence_core.py` — pure deterministic logic (no MCP imports), so it is unit-testable offline:
  - `extract_passages`: ~600-char chunking on sentence boundaries (with hard-split fallback for punctuation-less text), keyword-overlap scoring of claim terms (hits + coverage bonus), top-N.
  - `source_credibility`: rule tiers per spec Section 9 (.gov/.edu/.mil/.gov.in/.ac.in → 0.9, fact_checkers.json → 0.85, trusted_domains.json → 0.8, unknown+HTTPS → 0.5, unknown no-HTTPS → 0.4 [spec silent; documented choice], blogs/forums/social → 0.3).
  - `extract_date`: meta/`<time>` tags first, then ISO / US / EU / slash regexes → ISO string or None; `is_recent` helper for the +0.05 recency bonus.
  - `quote_in_passages`: case/whitespace-normalized substring + difflib fuzzy window (≥0.9), min length 10 — the Section 3.1 safeguard against invented quotes.
- `mcp_servers/evidence_server.py` — thin FastMCP wrapper (3 tools).
- `trusted_domains.json`, `fact_checkers.json` — small editable lists.
- `app/mcp_client.py` — evidence server added to MCPManager; response-shape-tolerant parsing (FastMCP returns lists/dicts inconsistently across `structuredContent.result` vs `content[0].text`).
- `app/nodes.py` — read_agent now: fetch → extract_passages → credibility (+0.05 recent, cap 0.3 if claim terms absent) → LLM summary from passages only. critique_agent: passages only (independence rule), quote check enforced (mismatch → stance unclear, confidence 0, note kept).
- `tests/test_evidence.py` — 31 offline tests (credibility tiers, passage ranking/limits, date formats, recency, quote matching). **All pass.**
- `samples/smoke_evidence.py` — MCP-protocol smoke of all 3 tools via MCPManager. **Passes.**
- `cli.py` — updated to the M2 read/critique signatures.

## Bugs found and fixed during M2

2. **Oversized chunks**: text without sentence punctuation produced single 15,000-char chunks. `_split_chunks` now hard-splits.
3. (M1 leftovers fixed in passing) awaited `raw.parse()`; MCP teardown now uses `AsyncExitStack` (LIFO), killing the anyio cancel-scope crash.
