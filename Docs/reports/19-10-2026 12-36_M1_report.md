## Spec deviations (all verified on this machine, recorded in AGENTS.md)
1. **Model**: spec's `llama-3.1-8b-instant` is retired — 404 `model_not_found`. Models available on this key: gpt-oss-20b/120b, qwen3.8-27b, allam-2-7b, guard/whisper/orpheus models. Using **`openai/gpt-oss-20b`** (cheapest viable general chat model, JSON mode OK).
2. **Search MCP**: npm `duckduckgo-mcp-server` triggers DDG anomaly detection from this network. Replaced with our own FastMCP server wrapping the `ddgs` lib (also keyless). Free engines are flaky (brave 429, google 403 observed), so the tool retries up to 3 times.
3. **mcp pinned `<2`**: mcp 2.3.0 renames FastMCP → MCPServer with breaking changes; spec says FastMCP. Downgraded to 1.30.0.
4. **`reasoning_effort="low"` + max_tokens 600**: `gpt-oss-20b` is a reasoning model; with 300 max_tokens the analysis ate the whole budget and Groq returned `json_validate_failed` (empty generation). Low effort + headroom fixes it. Final JSON output stays in the spec's size range.
5. langchain-mcp-adapters NOT installed — spec allows the official SDK; we already had `mcp` in `mini`.
